# Python Troubleshooting Guide

## ModuleNotFoundError

This error occurs when Python cannot locate an imported module.
Check that the package is installed in the active virtual environment.
Run Python using the correct interpreter and verify the project structure.

## Database Connection Errors

A database connection may fail because the server is stopped,
the host or port is incorrect, or the credentials are invalid.
Check the database server status and connection configuration.

## Virtual Environments

A virtual environment isolates project dependencies.
Activate the environment before installing packages or running scripts.
Use python -m pip to install packages through the active interpreter.
